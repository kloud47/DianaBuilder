
# Diana Web Builder - Application

-> A comprehensive SaaS platform that democratizes website creation through an intuitive, cost-effective solution. This multi-tenant architecture enables users to build professional websites with custom domain integration.

-> You could sign in as an Agency owner or if you are already part of an agency you must have been given access as a Subaccount user.

-> Agency owners can keep a keep track of their subaccounts & teams that are working in those subaccounts these teams have access to the tasks pipeline which can be used to assign work to team members in form of draggable bulletin board cards.

-> All subaccounts have access to the Web Editor platform in the application which can be used to edit websites and build your personalized websites with ease without any code.

-> All Agencies have their own media bucket which has a collection of images that can be used in web editor.
